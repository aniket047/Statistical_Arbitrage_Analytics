- [ ] **Git Installed?**

  If not: Download from https://git-scm.com/download/win

- [ ] **GitHub Account Created?**
  Visit https://github.com and sign up (takes 2 minutes)

- [ ] **GitHub Repository Created?**

## Execution (2 Minutes)

### Step 1: Configure Git (First Time Only)
```powershell
git config --global user.name "Your Name"
git config --global user.email "your@email.com"
```

### Step 2: Navigate to Project
```powershell
cd "c:\Users\anike\Downloads\Statistical_Arbitrage_Analytics_SAA_FINAL"
```

### Step 3: Initialize and Push
```powershell
# Initialize git
git init

# Add all files
git add .

# Create commit
git commit -m "Initial commit: Production-grade SAA system with regime detection and metrics"

# Add remote (replace YOUR_USERNAME)
git remote add origin https://github.com/YOUR_USERNAME/Statistical_Arbitrage_Analytics_SAA.git

# Push to GitHub
git branch -M main
git push -u origin main
```

When asked for password: **Use your Personal Access Token** (from https://github.com/settings/tokens)

## Troubleshooting

| Problem | Solution |
|---------|----------|
| `git not recognized` | Reinstall Git, restart PowerShell |
| `Authentication failed` | Use Personal Access Token, not password |
| `remote origin already exists` | Run: `git remote remove origin` first |
| `Large files rejected` | That's normal (.gitignore excludes them) |
| `Can't find directory` | Check current folder with `pwd` |
