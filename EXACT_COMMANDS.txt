# EXACT COMMANDS TO RUN RIGHT NOW

## Copy & Paste These 7 Commands Into PowerShell

**Replace `YOUR_USERNAME` before running!**

## Command 1️⃣
```powershell
cd "c:\Users\anike\Downloads\Statistical_Arbitrage_Analytics_SAA_FINAL"
```
👉 This moves to your project folder

---

## Command 2️⃣
```powershell
git init
```
👉 Initializes git in your project

---

## Command 3️⃣
```powershell
git add .
```
👉 Adds all your files to git

---

## Command 4️⃣
```powershell
git commit -m "Initial commit: Production-grade statistical arbitrage system"
```
👉 Creates your first commit with a message

---

## Command 5️⃣
```powershell
git remote add origin https://github.com/YOUR_USERNAME/Statistical_Arbitrage_Analytics_SAA.git
```
⚠️ **CHANGE THIS:**
- Replace `YOUR_USERNAME` with your GitHub username
- Example: `https://github.com/john-smith/Statistical_Arbitrage_Analytics_SAA.git`

👉 This connects to your GitHub repository

---

## Command 6️⃣
```powershell
git branch -M main
```
👉 Renames your branch to "main"

---

## Command 7️⃣
```powershell
git push -u origin main
```
👉 Pushes your code to GitHub

**When it asks for:**
- **Username:** Type your GitHub username
- **Password:** Paste your Personal Access Token (from https://github.com/settings/tokens)

---

## THAT'S IT! 🎉

Your code will now be on GitHub!

Visit: `https://github.com/YOUR_USERNAME/Statistical_Arbitrage_Analytics_SAA`

---

## DON'T HAVE PERSONAL ACCESS TOKEN YET?

1. Go to https://github.com/settings/tokens
2. Click "Generate new token (classic)"
3. Name: `GitHub Push`
4. Check: `repo`
5. Generate and COPY the token
6. Use it as password in Command 7
